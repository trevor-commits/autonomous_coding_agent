# PROJECT_INTENT

## Purpose

This repository implements the bounded policy and per-episode execution layer of a persistent autonomous partner. It accepts explicit coding objectives and typed global wake snapshots, selects only evidence-backed useful or creative opportunities, enforces deterministic authority and budgets, executes one scoped worktree through required quality/UI gates, and ends with a ready or not-ready decision backed by structured artifacts. Durable identity, goals, recurrence, approvals, learning promotion, and benefit truth remain in the existing global governor; this repo exists to make initiative safe and execution truthful, not to become a second scheduler, memory service, or portfolio control plane.

## Primary users

The primary user is Trevor, as operator and product owner of the global partner system. The runtime keeps four roles distinct: the global governor owns durable truth and wake timing; the stateless partner policy ranks bounded opportunities and emits one typed decision; the deterministic supervisor owns legality and completion; and Codex is the sole code-writing builder inside one run worktree. Independent auditors inspect code, receipts, artifacts, and live behavior before autonomy expands.

## Non-goals

This repository does not claim consciousness, feelings, divine approval, or reciprocal human attachment. It does not ingest raw transcripts or private content, store chain of thought, silently rewrite identity, or grant authority from personality/model prose. It does not support multi-writer execution, autonomous merge/deploy/publish/payment/credential/destructive actions, or production changes outside an exact operator gate. It does not replace Mission Control, the global autonomous loop, global memory/benefit surfaces, or add OpenClaw/Zep/another partner database.

## Success metrics

The current release is complete when a global identity/goals/health snapshot produces a deterministic observe/proposal decision; pre-approval dispatch is denied; a full exact proposal approval can produce one immutable sandbox envelope; ACA cross-binds its subject/hash/capabilities; the global executor confirms the identical approval is still current, unrevoked, and unexpired immediately before effects; the existing global queue can dry-run and execute it; the supervisor retains a verified worktree and hash-bound report; outcome reconciliation emits measured-benefit and expiring lesson candidates without promoting them; all kill switches work across race windows; the full legacy and partner suites pass; and a fresh independent audit is review-clean. L3 per-project approval removal is not part of the immediate proof because its 10-proposal, 80-percent acceptance, 10-completed-episode threshold and a separate operator-promotion proof must first be earned and reviewed.
