# Retrospective: Autonomous Partner Reposition

## What the release candidate contains

The existing repository was kept and repositioned. Its tested supervisor is now the bounded episode executor and evidence authority beneath the existing global governor, with a stateless partner-policy seam for personality-shaped initiative, exact approvals, outcome reconciliation, and candidate learning.

## Evidence

- 22/22 OpenSpec tasks complete on a clean-history release branch.
- The deterministic ACA suite discovers 181 tests: 180 pass and one opt-in live Codex test is skipped; the separately enabled real Codex containment probe also passes, along with strict OpenSpec validation and whitespace checks.
- One real `gpt-5.5`/high retained-worktree pilot completed with two successful 159-test runs.
- Independent and PR review through round 12 found and repaired approval, pre-effect command/filesystem containment, current safety-gate replay, receipt/evidence binding, benefit-measurement, diff, provenance, schema, concurrency, idempotency, CLI, archive, and learning-boundary defects. A fresh exact-tip verdict remains required before landing.
- `referencing` is now an explicit direct dependency so cross-schema executor-envelope validation uses a real registry instead of silently accepting incomplete nested documents; it was already present transitively through `jsonschema`.

## What worked

- Keeping durable ownership in the global governor prevented a second scheduler, identity store, or memory system.
- Evidence-first pilot failures exposed real command-boundary and completion-retirement defects before deployment.
- The independent audit loop found deeper approval-path problems that full green suites had not modeled.
- Honest unknown-benefit handling kept artifact production separate from adoption or life-improvement claims.

## What did not work at first

- The first envelope bound only approval id/hash, not the complete current authority document.
- Resolving paths before safety checks neutralized the intended symlink boundary.
- Descriptor binding covered the leaf but initially missed ancestor redirection.
- Candidate generation initially allowed overlapping model calls to overwrite active state, and wake-only idempotency let observe suppress proposal mode.
- Archive discovery and canonical purposes were initially left stale, while one CLI/error boundary was not structured consistently.
- The real builder used several harmless command shapes outside the finite grammar, so the pilot needed bounded grammar repairs rather than a permissive fallback.
- Post-effect diff checks were not sufficient for an untrusted builder: a PreToolUse guard and per-run Codex permission profile now reject unknown commands and constrain shell writes to the exact allowed paths before effects.

Each miss became a regression, a durable audit entry, and a narrower invariant. No failed pilot or review was relabeled as success.

## Deliberate deviations

- Persistent identity, goals, observations, approvals, learning promotion, benefit, and recurrence landed globally instead of in ACA.
- L3 stays disabled even when numerical maturity thresholds pass because exact operator-promotion proof is not yet specified.
- Deployment is observe-only; recurring execution remains unauthorized.

## Reusable lesson candidates

- Safety checks must apply to the operator-supplied original path before canonicalization can erase evidence of redirection.
- Effect-time authority must be one descriptor-bound lease over the exact document used for the final decision.
- Green validators do not prove the workflow; pilot, adversarial review, and live deployment are separate gates.
- A produced artifact is evidence of output, not evidence of adoption or benefit.

These are candidates for later promotion through the normal reliability/rule-review process; this retrospective does not silently create new global policy.
